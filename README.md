# 鼓谱拼图

输入 B 站视频链接，或选择本地视频，把纵向滚动的动态鼓谱拼成完整 PNG 长图。所有图像处理在本机完成，不需要模型 API Key。

## 启动

### macOS（推荐）

需要 Python 3.10 或以上，以及 FFmpeg / ffprobe。已安装 Homebrew 时，可执行：

```bash
brew install python ffmpeg
git clone https://github.com/jackieliuyc-cyber/drum-score-tool.git
cd drum-score-tool
chmod +x 启动鼓谱拼图.command
./启动鼓谱拼图.command
```

也可以下载仓库 ZIP、解压后，在项目文件夹内执行最后两条命令。首次启动会在 `.venv` 创建本地环境并联网安装依赖；仓库不包含虚拟环境或已下载的视频。

后续可双击 `启动鼓谱拼图.command`，浏览器会打开 **http://127.0.0.1:8765**。保持启动的终端窗口运行，使用结束后按 `Ctrl+C`。请保留整个项目文件夹，不要单独移动启动文件。

### 在其他电脑使用

需要 Python 3.10 或以上，以及 FFmpeg / ffprobe。

- macOS：先安装 Python；FFmpeg 可以用 `brew install ffmpeg` 安装。双击启动文件，首次启动会联网安装 Python 依赖。
- Windows：安装 Python 和 FFmpeg，并把它们加入 PATH；运行 `start.bat`。Windows 启动脚本已提供，尚未在 Windows 实机验证。
- Linux / 手动启动：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

端口被占用时：`python app.py --port 8766`。不自动打开浏览器：`python app.py --no-browser`。

## 使用

1. 粘贴 B站链接、BV 号或 b23.tv 分享链接，点击「读取视频」；也可以选择「本地视频」上传。
2. 检查预览。画面包含演奏者、字幕或其他内容时，拖动框选完整谱面。五线谱两侧、行上方的记号以及下方符干都要保留。
3. 需要时切换预览时间，并设置起止时间。快速滚动的视频可用「精细 · 每 0.5 秒」。
4. 点击「生成完整鼓谱」。完成后打开「检查谱行」核对顺序，可取消误识别行、上下移动后重新导出。
5. 点击「下载 PNG」。图片、原始视频、逐行截图和结果数据也保存在 `.runtime/<任务编号>/` 中。

重启后会恢复已完成任务；取消或失败的任务不会自动重跑。中间文件不会自动清理；不用时可关闭工具后删除 `.runtime` 以释放空间。

## 支持范围与实际限制

- 当前链接读取支持 **B 站公开视频**，包括 `?p=2` 这样的分 P 地址。其他平台请先保存视频，再上传本地文件。
- 适合白底深色、固定缩放比例的五线鼓谱。主要针对按阅读顺序向下推进的纵向滚动（不支持来回倒退）；无法连续对齐的翻页会作为新段保留，并提示人工检查。
- **不支持横向滚动拼接**、透视拍摄、持续缩放、多列阅读顺序推断、从鼓声自动扒谱。鼓谱必须已显示在视频中。
- 同页相邻多行会按上到下排列。相似的节奏不会仅因图案重复而被全局去重。
- 页面切换无重叠、谱行始终不完整、弹幕遮挡、行距太紧等情况下仍可能重行、漏行或截断；完整性应通过「检查谱行」确认。检测不到五线谱会报错，不会生成猜测的谱面。
- 蓝色播放标记尽量通过选帧避开，剩余标记转为灰度。输出保留原图形状，不用生成式模型重绘音符。
- 输入上限 1 GB / 30 分钟；识别宽度最高 1280 px，最多 1800 个采样帧及 500 行，输出不超过 1 亿像素。
- B站可能要求登录或限制画质；工具使用匿名公开接口，不读取浏览器 Cookie。若读取失败，请上传已经下载的视频。
- 工具仅监听 `127.0.0.1`，无需账号，也不上传本地视频到远程服务。

## 已完成的验证

用 `BV1Le411i7Bp`（孙燕姿《第一天》，约 4 分 16 秒）完整测试：自动输出 **36 行**。每行均与此前人工核对的截图顺序比对；36 行图像匹配得分均大于 0.90。该分数仅用于本视频的回归检查，不代表对所有视频的识别准确率。

`tests/` 提供合成谱面的回归用例，覆盖相似节奏滚动、场景切换、位置去重、裁切范围、导出筛选，以及不合法输入。

```bash
python -m unittest discover -s tests -v
```

## 文件结构

```text
app.py          本地服务、后台任务、上传与结果接口
sources.py      B站链接解析、公开媒体下载、FFmpeg 元信息与预览
score.py        五线谱识别、滚动对齐、选帧、拼接
web/            无前端构建依赖的中文界面
tests/          算法与输入验证测试
requirements.txt
```

处理流程：按时间采样 → 检测五条等距谱线 → 对齐相邻画面 → 按文档位置追踪谱行 → 选取遮挡较少的画面 → 拼接导出。FFmpeg 流式解码，避免把整段视频的全部截图同时装入内存。
