# Mac 版短谱行漏识别修复

## 原因和修复

原谱线检测要求一行横线的覆盖率超过最强横线的 60%，在同一画面同时出现长行和短行时，会漏掉部分短结束行与换拍行。阈值调整为 35%，继续保留水平形态学过滤、最低覆盖率及五条等距谱线校验。

## 验证

- 用户提供的 88.43 秒、1280 × 720 H.264 本地视频，修复前输出 13 行；修复后输出 15 行，恢复第 53、63 小节起始的短行。
- 使用原文件重新上传到运行中的 Mac 本地服务，经过视频探测、预览、全片处理和 PNG 下载，输出 1352 × 2370 像素。15 张谱行图片与直接调用引擎重跑的结果逐一一致。
- 新增三项回归：短行与长行混排、非五条等距横线不误识别、短中间行与最后一行在视频编码/解码后均完整保留。
- GitHub 发布代码的干净副本通过全部 24 项 Python 测试。本地包含录屏开发功能的版本通过全部 26 项 Python 测试。
- 原视频和提取图片仅留在用户本机，不加入源码仓库。部分播放标记仍可能残留，需与原视频核对；不宣称所有类型乐谱均能无误识别。
